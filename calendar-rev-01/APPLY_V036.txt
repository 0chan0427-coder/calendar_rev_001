현재 V035가 적용된 저장소에 덮어쓰는 수정본입니다.
앞선 V033~V035의 셔츠/속옷/부츠 수정도 유지됩니다.
새로운 의상과 동물은 추가하지 않았습니다.

적용 순서
1. Supabase → SQL Editor → New query에서 supabase/016_face_items.sql 내용을 붙여넣고 Run.
   기존 013/015가 적용되어 있어야 합니다. 016은 재실행 가능하며 보유품/포인트/착용 상태를 초기화하지 않습니다.
2. src 폴더의 변경 파일 7개를 GitHub의 같은 경로에 덮어쓰기.
   - src/lib/avatarRaster.ts
   - src/lib/avatarMotion.ts (새 파일)
   - src/data/wardrobe.ts
   - src/styles/world.css
   - src/components/world/CharacterAvatar.tsx
   - src/components/world/WearableThumbnail.tsx
   - src/components/world/WardrobePanel.tsx
   저장소 맨 위에서 src 폴더를 끌어넣으면 같은 폴더 구조로 올라갑니다.
   supabase/016_face_items.sql도 기록용으로 업로드할 수 있지만 GitHub 업로드만으로 DB에 적용되지는 않습니다.
3. Commit changes 후 Vercel 배포 완료 → 새로고침.
4. 미니미 꾸미기에서 기본 브라운 눈을 선택하고, 화장/안경을 조합해 확인.

이미지 업로드/패키지 설치는 필요 없습니다. 이 안내문과 미리보기 HTML은 GitHub에 올리지 않아도 됩니다.

움직임
- 착용한 모든 부위가 같은 그룹에서 4초 주기로 0.6% 이내로 함께 들썩입니다.
- 기본 브라운 눈은 6.4초 주기로 약 0.13초 동안 감깁니다. 열린 눈과 감긴 눈은 동시에 보이지 않습니다.
- 웃는 눈은 이미 감긴 표정이므로 추가 깜빡임이 없습니다.
- 모브 아이 메이크업의 눈꺼풀 화장도 열린/감긴 눈과 함께 바뀝니다.
- 안경/볼터치/주근깨는 눈 깜빡임 중 유지됩니다.
- 꾸미기 화면의 움직임 켜짐/꺼짐 버튼은 같은 브라우저에 저장됩니다. 계정 간 동기화 설정은 아닙니다.
- OS/브라우저에서 움직임 줄이기를 설정한 경우 애니메이션을 멈춥니다.
- 품목 목록의 작은 썸네일은 정지 상태로 표시합니다.

추가 품목
- 살구빛 볼터치 500P
- 살구 주근깨 메이크업 700P (살구 볼터치와 주근깨 조합)
- 모브 아이 메이크업 800P (눈가 음영과 은은한 볼터치 조합)
- 올리브 라운드 사각 안경 1,000P
- 로즈골드 타원 안경 1,000P
기존 화장/안경은 유지됩니다. 화장은 한 종류씩 선택하며, 안경은 화장과 독립적으로 선택합니다.

검증
- 남녀 × 화장 6종 × 안경 5종 × 눈 열림/감김 2상태 = 120가지 조합.
- 열린 눈/감긴 눈 중 하나만 표시, 모브 음영 동기화, 움직임 줄이기 대응.
- 프로덕션 앱에서 움직임 토글의 월드/꾸미기 동시 적용, 새로고침 후 꺼짐 유지.
- 테스트용 서버 응답에서 신규 품목 착용 저장/복원 및 모바일 저장 버튼 확인.
- 로컬 PostgreSQL 호환 DB에서 016 반복 실행, 구매 중복 차감 방지, 소유권 검증, 신규 화장/안경 조합 저장.
- 프로덕션 빌드 및 월드 범위 TypeScript 검사 통과.
실제 운영 Supabase 계정에 접속하여 구매/저장한 검증은 아닙니다.

앞으로 얼굴 아이템을 추가할 때
눈은 열림/감김 두 상태를 같은 좌표로 제작해야 합니다.
눈꺼풀에 붙는 화장은 두 상태를 함께 제작하고 눈과 같은 시간축으로 교체해야 합니다.
안경/볼터치/주근깨는 눈 위에 덧칠하지 않고 독립 레이어로 유지합니다.
임의의 새 이미지를 올리는 것만으로 자동 호환되는 구조는 아닙니다.
