씩씩이 월드 017 - 소셜 기능 통합

반영 내용
- 1촌 목록에서 공통 얼굴/파레트 이미지 제거
- 방명록 비밀글 작성 기능 추가
- 비밀글은 다른 방문자에게 '🔒 비밀글 작성자 / 비밀글입니다'로 표시
- 미니홈피 주인에게는 비밀글 실제 작성자와 내용 표시
- 비밀글 답글도 자동으로 비밀 처리
- 오늘 출석한 멤버 패널 추가
- 주간 랭킹에 역대 주간 기록 추가
- '씩씩이왕' 문구를 '씩씩이'로 통일
- TODAY / TOTAL 방문수는 유지하고 방문자 명단은 추가하지 않음
- 알림함 추가: 방명록, 답글, 랭킹 결과, 포인트 지급, 선물 도착
- 포인트샵에서 현재 월드 멤버에게 아이템 선물 기능 추가
- 선물 아이템은 수신자 인벤토리에 +1, 발신자 포인트 차감, 수신자 알림 생성
- 구매/선물 가격을 서버 아이템 카탈로그에서 검증하도록 추가
- Supabase RLS/RPC 기반 비밀글 및 소셜 데이터 접근 제어 추가

주의
- SQL migration: supabase/009_world_social_system.sql 을 Supabase에서 1회 실행하세요.
- 기존 001~008은 그대로 유지합니다.
- 전체 Vite build는 현재 작업 환경의 의존성 상태상 검증하지 않았습니다.
