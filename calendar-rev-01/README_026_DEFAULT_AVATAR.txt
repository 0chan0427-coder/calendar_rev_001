026 기본 미니미 기준
- 여성: B 스타일 캐릭터 계열의 기본 캐릭터 자산을 default asset으로 사용
- 남성: B 스타일 캐릭터 계열의 기본 캐릭터 자산을 default asset으로 사용
- 좌측 프로필과 미니룸 캐릭터는 동일한 avatarGender 상태를 사용하므로 성별 변경 시 함께 바뀜
- 향후 실제 기본 단발/반삭 투명 레이어 자산이 준비되면 default asset 파일만 교체 가능
- 캐릭터 비율/디자인은 고정하고 헤어, 얼굴/피부, 화장, 모자, 상의, 하의, 신발, 악세서리, 등 장식의 독립 레이어 확장을 전제로 함
