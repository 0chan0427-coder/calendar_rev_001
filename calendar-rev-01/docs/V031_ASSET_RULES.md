# 고정 몸체 기반 에셋 규칙

시안의 단순한 2D SD 방향을 실제 조합용 SVG로 제작했다. 시안 그림을 잘라 붙이거나
기존 원본의 색상을 폴리곤으로 덮지 않는다. SVG는 앱의 원본 에셋으로 유지한다.

## 파일 구조

- public/world/avatar-v2/base: 몸체, 얼굴, 손의 고정 원본
- public/world/avatar-v2/hair: 각 헤어의 front/back 한 쌍
- public/world/avatar-v2/tops: 소매 포함 상의
- public/world/avatar-v2/bottoms: 하의
- public/world/avatar-v2/shoes: 실제 발에 맞춘 신발
- public/world/avatar-v2/accessories: 별도 장식
- public/world/companions-v2: 같은 그림체의 동물과 장식
- src/data/wardrobe.ts: ID/이름/부위/가격/이미지/뒷머리 등록
- supabase/014_modular_avatar_catalog.sql: 판매 대상과 가격 등록

## 좌표와 레이어

사람의 모든 파일은 viewBox 0 0 256 384를 공유한다. 투명 여백을 잘라내지 않는다.
얼굴, 발, 어깨 위치는 고정이다. 새 코디를 제작할 때 몸체와 얼굴을 다시 그리지 않는다.

| 순서 | 부위 |
|---|---|
| 5 | 뒷머리 |
| 10 | 몸체·팔·다리·발 |
| 20 | 신발 |
| 30 | 하의 |
| 40 | 상의·소매 |
| 50 | 손 |
| 60 | 얼굴·귀 |
| 70 | 앞머리 |
| 80 | 장식 |

상의가 하의 허리선을 덮고, 긴바지가 부츠 윗부분을 덮는다.
상의와 하의는 각각 한 벌만 선택된다. 교체 전 의상 파일은 렌더링하지 않는다.
기본 코디는 반팔 티+크림 반바지+크림 스니커즈이며 초기화 시 이 조합으로 돌아간다.

몸체와 얼굴은 별도 원본이다. 향후 피부색을 추가할 때도 이 원본의 대응 파일을
제작하고 기준점을 동일하게 유지한다. 기존 눈 위에 선을 얹는 눈 깜빡임은 사용하지 않는다.

## 동물

동물 원본은 viewBox 0 0 256 256을 공유한다. 같은 체형의 고양이 색상·무늬는
선과 얼굴을 고정하고 털 부분만 별도 도형 색·무늬로 제작했다. 리본은 독립 파일이다.
개와 토끼의 독립 장식·털색은 추가 제작과 호환성 검증이 필요하다.
다른 체형의 동물끼리는 목/귀 위치가 다르므로 장식 위치를 자동 공유하지 않는다.

## 아이템을 추가할 때

1. 같은 캔버스에 원본 몸체를 잠금 참조로 놓고 해당 부위의 SVG를 만든다.
2. 테두리 #654b40, 기본 선 두께 2.4(사람)/3(동물), 단순한 그림자 기준을 유지한다.
3. wardrobe.ts와 서버 카탈로그 SQL에 같은 ID·부위·대상·가격을 등록한다.
4. 썸네일 자르기는 WearableThumbnail의 viewBox에서만 하고 원본 좌표는 유지한다.
5. 짧은/긴 머리, 반팔/긴팔, 반바지/긴바지/스커트, 스니커즈/부츠와 교차 확인한다.
6. 의상 끝단, 손목, 목선, 허리, 발목에서 원본 피부·다른 의상이 튀어나오는지 확인한다.

이 구조는 동일 캐릭터와 정렬을 유지하기 위한 제작 규격이다.
임의로 생성한 그림을 등록만 해서 모든 부위가 자동 정렬되는 구조는 아니다.
