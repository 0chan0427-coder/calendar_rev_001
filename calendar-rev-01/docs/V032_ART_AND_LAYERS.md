# V032 실제 아트와 레이어

## 아트 원칙

승인한 4열 남녀 베이스 비교 이미지의 남녀 BASE를 참조해 내장 이미지 생성 도구로
남녀 독립 PNG를 제작했다. 같은 그림체의 눈, 헤어, 상하의, 신발 PNG를 별도로 제작했다.
이전 V031의 수작업 벡터 캐릭터로 대체하지 않는다.

분리 제작/정렬 과정이 있으므로 승인 그림과 픽셀 단위로 동일하다는 의미는 아니다.
미리보기와 앱이 같은 실제 원본을 사용한다는 점을 보장하는 구조다.

## 파일

- public/world/avatar-v3: 남녀 눈 없는 몸체, 투명 눈·눈썹, 숏컷·단발,
  블루 셔츠·피치 맨투맨, 반바지·긴바지, 스니커즈·부츠의 PNG.
- src/data/avatarRaster.ts: 원본 크기와 알파 영역 경계.
- src/data/wardrobe.ts: 슬롯·아이템·가격·호환 목록.
- src/lib/avatarRaster.ts: 앱과 오프라인 미리보기가 공유하는 실제 합성 함수.
- src/components/world/CharacterAvatar.tsx: React 표시.
- src/components/world/WearableThumbnail.tsx: 실제 아이템/얼굴의 미리보기.
- supabase/015_approved_raster_avatar.sql: 새로운 슬롯/아이템을 서버 카탈로그에 등록.

## 합성

1024×1536의 고정 몸체 좌표계를 사용한다. 원본 PNG 파일을 잘라 수정하거나
매번 다른 몸체로 다시 그리지 않고 SVG 이미지 배치로 장착 위치를 관리한다.
SVG는 몸체를 그리는 대체 그림이 아니라 실제 PNG의 배치·마스크·합성을 담당한다.

순서: 뒷머리 → 눈 없는 몸체 → 피부 톤 → 눈/눈썹 → 볼터치 → 신발 → 하의 → 상의
→ 손 → 안경 → 앞머리 → 리본.
머리의 얼굴 개구부와 손 부위는 고정 마스크로 정렬한다.
PNG에 남은 낮은 알파의 바깥 그림자를 제거하고 의상 내부가 비치지 않도록
표시 단계에서 알파를 정리한다. 원본 PNG 자체는 보존한다.

## 얼굴

기본 눈은 피부가 없는 독립 PNG다. 바탕 몸체에 기존 눈이 남아 있지 않다.
웃는 눈은 같은 눈 위치에 닫힌 눈 곡선을 그리는 정지 표정이다.
안경과 볼터치는 얼굴 기준 좌표의 독립 도형이므로 각각 해제할 수 있다.
피부 톤은 노출 피부 마스크에만 색 변환을 적용해 원래 명암을 유지한다.
눈·볼터치·의상·헤어·안경은 피부 변환 이후 별도 표시한다.
깜빡임 애니메이션은 넣지 않는다.

## 데이터와 구형 호환

013의 world_equipment에 face/skin/makeup/glasses 슬롯을 독립 저장한다.
서버는 슬롯·대상·구매 여부를 검증한다. 새로운 테이블은 추가하지 않는다.
015 카탈로그는 반복 실행 가능하고 기존 구매나 착용을 일괄 삭제하지 않는다.
지원되지 않는 예전 아이템은 렌더러에서 기본값으로 대체하며,
새 착용을 저장하기 전까지 서버의 이전 기록은 유지된다.

## 이미지 생성 프롬프트 요약

내장 imagegen 사용. 승인 그림을 참조해 아래를 실제 투명 PNG로 제작했다.
- 남녀 BASE 각각: 얼굴·체형·자세·명암 유지, 전신·맨발, 민소매와 속바지, 배경/문자 제거.
- 눈 없는 바탕: 몸체/입/코 유지, 눈·눈썹·볼터치를 자연스러운 피부로 대체.
- 눈: 원래 브라운 눈과 눈썹만, 피부/코/입/볼터치 없이 투명 배경.
- 숏컷/단발: 원래 윤곽·결·광택 유지, 머리카락만 분리.
- 셔츠/맨투맨/반바지/긴바지/신발: 원래 앞모습 자세·디자인·일러스트 질감을 유지,
  착용자 없이 의상 또는 신발 한 쌍만 투명 배경에 분리.

저장 경로는 위 public/world/avatar-v3이며, 미리보기에도 같은 파일 바이트를 포함한다.
