# V057 낚시·수족관 시험판

## 범위와 위치

광장 → 낚시 / 보관함 / 도감 / 순위 / 미끼 상점.
미니홈피 → 방 / 정원 / 수족관. 친구의 수족관도 볼 수 있다.
이 버전에는 물고기 12종, 낚시터 2곳(민물·바다), 미끼 4종을 포함한다.
기존 동물·미니미·가구 이미지는 변경하지 않는다. 새로운 미니게임 3~4개 중 낚시부터 전체 흐름을 검증하는 버전이다.

## 낚시와 확률

- 무료 기본 미끼는 무제한이다. 모든 물고기는 기본 미끼로도 잡을 수 있다.
- 서버가 종과 크기, 판매가, 입질 시간을 결정한다. 찌를 던진 결과를 바꾸려고 새로고침해도 새로 추첨되지 않는다.
- 입질까지 8~16초, 입질 뒤 12초 안에 ‘지금 낚기’를 누르면 잡힌다. 놓치거나 취소하면 미끼는 반환되지 않는다. 서버 트랜잭션 오류로 실패한 시작은 차감도 롤백된다.
- 기본 미끼의 민물 확률: 붕어 40%, 잉어 25%, 메기 27%, 무지개송어 7%, 비단잉어 0.98%, 황금잉어 0.02%.
- 기본 미끼의 바다 확률: 고등어 64.99%, 흰동가리 27%, 블루탱 7%, 참치 0.9%, 만타가오리 0.1%, 실러캔스 0.01%.
- 미끼 선택 화면에서 해당 장소·미끼의 개별 확률을 소수점 4자리까지 공개한다. 희귀종 확정 획득 보장은 없다. 0.01%는 평균 1만 회당 1회 수준이지, 1만 회 이내 획득 보장이 아니다.
- 크기는 종별 범위 안에서 별도로 추첨한다. 세 균등 난수의 평균으로 중간 크기가 잘 나오게 하고, 대물 미끼는 그 분포를 큰 쪽으로 옮긴다. 종류의 출현 확률과 크기 효과를 구분한다.

## 미끼·판매·환불

| 미끼 | 가격 | 효과 |
|---|---:|---|
| 기본 | 0P | 모든 물고기 출현 |
| 고급 | 10개 100P | 드묾·희귀 이상의 비중 증가 |
| 대물 | 10개 200P | 종 확률은 기본과 동일, 큰 개체 비중 증가 |
| 특수 | 10개 300P | 희귀 이상의 비중을 더 증가 |

포획 자체로 포인트를 주지 않고 판매할 때 지급한다. 도감 보상은 별도의 일회성 보상이다.
판매가는 포획 때 확정하여 저장한다. 종별 기본 가격에 크기 보정 0.75~1.5배를 적용하고 정수 포인트로 내린다.
하루 판매 상한은 500P, 한국 시간 자정 기준이다. 미끼 비용 차감과 별개로 판매 수입 합계에 적용한다.
판매 선택 금액이 남은 한도를 넘으면 전체 판매를 거절하고 물고기를 그대로 보관한다. 가격 일부만 주고 개체를 가져가지 않는다.
보관함은 100마리까지이며 가득 차면 새로 던지기 전에 판매해야 한다. 판매 한도 이후에도 보관 공간이 있으면 수집·기록 갱신은 계속 가능하다.
미끼는 구매 내역별 남은 수량을 기한 없이 당시 개당 가격으로 환불한다. 사용한 수량은 제외하고, 오래된 구매분부터 사용한다. 일부 사용한 100P짜리 10개 묶음이 9개 남았다면 90P 환불이다.
미끼 구매는 기존 포인트 잔액과 동일한 원장을 사용한다. 캐릭터/가구 구매와 동일한 사용자 경제 잠금으로 동시 결제를 직렬화한다. 미끼 구매·환불은 낚시의 ‘미끼 상점’ 안에서 확인한다.

## 도감·순위·보관

- 물고기는 개체마다 고유 ID가 있다. 판매 여부, 잠금, 수족관 전시, 크기 기록을 같은 개체에 연결한다.
- 판매해도 도감 수집, 포획 횟수, 최초 날짜, 개인 최대 길이, 순위 기록은 남는다.
- 잠금 또는 전시 중인 개체는 선택 판매에서도 서버에서 거절한다. 일괄 선택은 기본적으로 일반·드묾만 고른다. 희귀종은 직접 선택하고 확인해야 판매된다.
- 도감 보상은 특별 희귀를 제외한 3/6/10종에 각각 100/200/300P, 자동 1회 지급한다. 최대 600P이며 판매 상한과 별개다.
- 순위는 종별 사용자당 최대 한 개체, 상위 20명이다. 동률은 먼저 잡은 기록이 우선이다. 도감 수집 상위 20명도 표시한다. 이번 버전의 순위는 역대 기록이며 주간 순위는 포함하지 않는다.

## 수족관

한 사용자당 한 마리만 전시한다. 자신이 잡아 현재 보유한 개체만 가능하다.
교체 시 기존 전시 개체는 보관함에 남는다. 판매한 개체를 도감 기록만으로 다시 전시할 수 없다.
물고기는 좌우로 천천히 왕복하고 끝에서 몸의 방향을 바꾼다. 작은 상하 움직임도 적용한다. 종과 개체 크기에 따라 표시 크기와 이동 시간이 달라진다.
실제 길이를 동일 비율로 옮기지는 않는다. 작은 종이 안 보이거나 큰 종이 어항을 가리는 것을 막기 위해 표시 범위를 제한한다.
브라우저의 ‘동작 줄이기’ 설정에서는 움직임을 멈춘다. 첫 버전에는 몸 전체를 굽히는 골격 애니메이션이나 종별 꼬리 마스크는 포함하지 않는다.
다크모드에서 동물에게 생겼던 문제를 반복하지 않도록 물고기는 캔버스에 그린다. 60종 도감의 메모리를 고려해 축소 원본을 공유하고 표시 크기에 맞춰 캔버스를 생성한다.

## 서버·재시도·접근 권한

모든 쓰기는 인증된 사용자에 한정한 SECURITY DEFINER RPC로 처리한다. 새 테이블은 RLS를 켜고 클라이언트 직접 읽기/쓰기를 허용하지 않는다. 결과를 숨겨야 하는 대기 중 낚시 원본도 직접 조회할 수 없다.
새 함수에는 authenticated 실행 권한을 명시하고, 내부 난수 및 비공개 추출 함수는 직접 실행하지 못하게 한다.
시작·구매·판매 요청은 UUID로 중복을 방지한다. 포획 완료는 낚시 ID로 한 번만 처리한다. 네트워크 응답을 잃으면 같은 요청을 다시 보내 기존 결과를 받는다. 진행 중인 확인 요청은 사용자별 sessionStorage에 보관한다.
서버가 기다리는 시간을 검사하고 클라이언트가 물고기 종류·크기·판매 가격을 제출하지 못하게 한다. 이는 자동화를 완전히 탐지하는 봇 방지 시스템은 아니며, 첫 시험판에는 별도 CAPTCHA/행동 탐지 기능을 넣지 않았다.
판매와 전시·잠금·환불에도 같은 경제 잠금을 적용하여 소유 상태 변경과 포인트 지급을 함께 처리한다.

## 60종으로 확장

1. 기존 id는 유지하고 src/data/fishing-catalog.json에 종/장소/미끼를 추가한다. 장소별 출현 가중치, 종별 크기·가격·표시 크기와 투명 PNG/crop을 함께 등록한다.
2. PNG 폴더는 각각 20개 이하, 개별 파일은 25MiB 미만으로 나눈다. fishing-058-01 같은 새 폴더도 검사기가 허용한다.
3. 이미 적용한 027을 수정해서 끝내지 않는다. JSON의 migration을 다음 SQL 파일명으로 바꾸고 node scripts/sync-fishing-catalog.mjs로 다음 카탈로그 전용 마이그레이션을 생성한다. 새 파일이 없으면 begin/commit과 upsert만 생성한다. 초기 사용자에게는 027부터 순서대로 적용한다.
4. npm run build는 모든 이미지·좌표·크기·확률 가중치·미끼 효과 및 동봉 SQL seed의 일치를 확인한다. SQL을 GitHub에 올리지 않는 경우에도 이미지 검사는 유지하고 SQL 유무 때문에 빌드를 중단하지 않는다.
5. 새 이미지의 좌우 방향/투명 배경/잘림은 직접 검토한다. 여러 종을 한 이미지로 합쳐 사용하지 않는다. 가격은 판매 상한 전 기대 수익을 산출해 무료 미끼보다 유료 미끼가 무조건 돈을 더 버는 수단이 되지 않게 조정한다.

## 검증 범위

- 독립 PostgreSQL 엔진에 실제 027 SQL을 적용하여 인증·직접 테이블 접근 제한, 비공개 결과, 이른 낚기 거절, 중복 시작/포획/판매/구매 방지, 소유권, 미끼 부분 환불, 판매 한도/한국 날짜, 잠금·전시 보호, 판매 후 도감·순위, 일회성 도감 보상, 재실행 시 기록 보존 확인.
- Chromium에서 같은 SQL 함수에 연결한 테스트 화면으로 무료 낚시→새로고침→포획→잠금→전시→왕복 움직임→전시 해제→판매→도감·순위 확인.
- 미끼 결제가 DB에서 성공한 뒤 응답만 끊는 상황을 재현하고, 재시도해도 재결제·재지급되지 않는지 확인. 미사용 수량 환불 확인.
- 320/390/1280 화면 및 강제 다크 변환의 물고기 캔버스 색 유지, 동작 줄이기에서 애니메이션 중지 확인.
- PNG 12종 전체 디코딩 및 투명도/크롭/완전성 검사. 관련 TypeScript 검사 및 테스트용 Supabase 환경변수를 사용한 프로덕션 빌드 확인.
- 실제 사용자 Supabase 데이터에 테스트 물고기나 포인트를 넣지 않았다. 삼성 인터넷/Safari 실기기 시험은 수행하지 못했다.
